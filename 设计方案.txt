三类顶点
Process：
process_id=pid + name
pid=proc.pid
name=proc.name
exepath=proc.exepath
args=proc.args
cwd=proc.cwd

File：
file_id=path
path：优先从fd=5(<f>/tmp/a)这样的fd=路径中提取，若提取不到则取evt.arg.filename
type=fd.type

Network：
network_id=protocol + lip + lport + rip + rport
protocol=fd.l4proto
lip=fd.lip
lport=fd.lport
rip=fd.rip
rport=fd.rport



五种事件边
Process -> Process
Process -> File
File -> Process
Process -> Network
Network -> Process

syscall=evt.type
